# 多跳QA合成流程详解

## 🎯 核心概念

**QA合成（QA Synthesis）** = 将多个单跳QA组合成一个复杂的多跳QA的过程

```
输入: 单跳QA-1 + 单跳QA-2 + ... 
       ↓
   [智能合成]
       ↓
输出: 多跳QA（需要多步推理才能回答）
```

---

## 🔄 完整合成流程（端到端）

```
┌──────────────────────────────────────────────────────────────────────┐
│                    Multi-hop QA Synthesis Pipeline                    │
└──────────────────────────────────────────────────────────────────────┘

【输入】单跳QA数据集
  │
  │  格式: JSONL
  │  结构: {id, question, answer, chunk, paper_name}
  │  数量: N (如5000条)
  │
  ▼
┌──────────────────────────────────────────────────────────────────────┐
│ 阶段1: 知识库构建与索引                                               │
├──────────────────────────────────────────────────────────────────────┤
│                                                                       │
│  ┌────────────────────────────────────────────────────────────────┐ │
│  │ Step 1.1: 加载单跳QA数据                                       │ │
│  │  ├─ 读取JSONL文件                                              │ │
│  │  ├─ 验证chunk字段完整性                                        │ │
│  │  └─ 构建QA字典: {qa_id: qa_data}                              │ │
│  └────────────────────────────────────────────────────────────────┘ │
│                            │                                          │
│                            ▼                                          │
│  ┌────────────────────────────────────────────────────────────────┐ │
│  │ Step 1.2: 构建多级索引                                         │ │
│  │                                                                 │ │
│  │  论文级索引:                                                    │ │
│  │  ├─ paper_to_qas: {"paper_A": [qa_1, qa_2, ...]}             │ │
│  │  └─ qa_to_paper: {qa_1: "paper_A", ...}                       │ │
│  │                                                                 │ │
│  │  实体级索引（倒排索引）:                                        │ │
│  │  ├─ 提取技术实体: [半导体, GaN, 载流子, ...]                  │ │
│  │  ├─ entity_to_qas: {"GaN": [qa_3, qa_5, ...]}                │ │
│  │  └─ qa_to_entities: {qa_1: ["半导体", "材料"], ...}          │ │
│  └────────────────────────────────────────────────────────────────┘ │
│                                                                       │
└──────────────────────────────────────────────────────────────────────┘
                             │
                             ▼
┌──────────────────────────────────────────────────────────────────────┐
│ 阶段2: 智能单跳选择（Smart Single-hop Selection）⭐                   │
├──────────────────────────────────────────────────────────────────────┤
│                                                                       │
│  输入: num_hops = 2 (目标跳数)                                       │
│                                                                       │
│  ┌────────────────────────────────────────────────────────────────┐ │
│  │ Step 2.1: 随机选择第一个单跳QA（作为起点）                     │ │
│  │  base_qa = random.choice(qa_ids)                               │ │
│  └────────────────────────────────────────────────────────────────┘ │
│                            │                                          │
│                            ▼                                          │
│  ┌────────────────────────────────────────────────────────────────┐ │
│  │ Step 2.2: 智能桥接算法（找到可链接的QA）⭐⭐⭐                  │ │
│  │                                                                 │ │
│  │  FOR i IN range(num_hops - 1):                                 │ │
│  │                                                                 │ │
│  │    ┌─────────────────────────────────────────────────────────┐│ │
│  │    │ 2.2.1 提取桥接实体                                      ││ │
│  │    │  ├─ 从base_qa.answer中提取关键实体                     ││ │
│  │    │  │   例如: "载流子迁移率", "GaN", "界面态"             ││ │
│  │    │  └─ entities = extract_keywords(base_qa.answer)         ││ │
│  │    └─────────────────────────────────────────────────────────┘│ │
│  │                        │                                        │ │
│  │                        ▼                                        │ │
│  │    ┌─────────────────────────────────────────────────────────┐│ │
│  │    │ 2.2.2 查找可桥接的QA                                   ││ │
│  │    │  FOR EACH entity IN entities:                           ││ │
│  │    │    Find QAs where entity ∈ next_qa.question             ││ │
│  │    │                                                          ││ │
│  │    │  例如:                                                   ││ │
│  │    │  ├─ base_qa.answer提到 "载流子迁移率"                  ││ │
│  │    │  └─ 找到next_qa.question包含 "载流子迁移率"            ││ │
│  │    │      → 形成桥接！                                       ││ │
│  │    └─────────────────────────────────────────────────────────┘│ │
│  │                        │                                        │ │
│  │                        ▼                                        │ │
│  │    ┌─────────────────────────────────────────────────────────┐│ │
│  │    │ 2.2.3 推断桥接类型                                      ││ │
│  │    │  IF "为什么" in next_qa.question:                       ││ │
│  │    │    bridge_type = "causal" (因果推理)                    ││ │
│  │    │  ELIF "提升" in next_qa.question:                       ││ │
│  │    │    bridge_type = "compositional" (组合推理)             ││ │
│  │    │  ELSE:                                                   ││ │
│  │    │    bridge_type = "inferential" (推断推理)               ││ │
│  │    └─────────────────────────────────────────────────────────┘│ │
│  │                        │                                        │ │
│  │                        ▼                                        │ │
│  │    ┌─────────────────────────────────────────────────────────┐│ │
│  │    │ 2.2.4 优先跨论文桥接 ⭐                                ││ │
│  │    │  candidates = bridgeable_qas                            ││ │
│  │    │  cross_paper = [qa for qa in candidates                ││ │
│  │    │                 if qa_to_paper[qa] != base_paper]      ││ │
│  │    │  same_paper = [qa for qa in candidates                 ││ │
│  │    │                if qa_to_paper[qa] == base_paper]       ││ │
│  │    │                                                          ││ │
│  │    │  优先级: cross_paper > same_paper                       ││ │
│  │    │  (跨论文链接更有价值)                                   ││ │
│  │    └─────────────────────────────────────────────────────────┘│ │
│  │                        │                                        │ │
│  │                        ▼                                        │ │
│  │    ┌─────────────────────────────────────────────────────────┐│ │
│  │    │ 2.2.5 选择下一个QA                                     ││ │
│  │    │  next_qa = random.choice(cross_paper or same_paper)    ││ │
│  │    │  selected_ids.append(next_qa)                           ││ │
│  │    │  base_qa = next_qa  # 更新base，继续链接               ││ │
│  │    └─────────────────────────────────────────────────────────┘│ │
│  │                                                                 │ │
│  └────────────────────────────────────────────────────────────────┘ │
│                            │                                          │
│                            ▼                                          │
│  ┌────────────────────────────────────────────────────────────────┐ │
│  │ Step 2.3: 生成桥接描述                                         │ │
│  │  bridge_info = "QA-1的答案中提到的'载流子'是QA-2问题的基础"  │ │
│  └────────────────────────────────────────────────────────────────┘ │
│                                                                       │
│  输出:                                                               │
│  ├─ selected_qa_ids: [qa_1, qa_2, ...]                             │
│  ├─ bridge_info: "桥接描述"                                         │
│  └─ bridge_type: "causal"/"compositional"/"inferential"            │
│                                                                       │
└──────────────────────────────────────────────────────────────────────┘
                             │
                             ▼
┌──────────────────────────────────────────────────────────────────────┐
│ 阶段3: LLM合成多跳QA（基于chunk约束）⭐⭐⭐                           │
├──────────────────────────────────────────────────────────────────────┤
│                                                                       │
│  输入: selected_qa_ids, bridge_info, bridge_type                    │
│                                                                       │
│  ┌────────────────────────────────────────────────────────────────┐ │
│  │ Step 3.1: 构建合成Prompt                                       │ │
│  │                                                                 │ │
│  │  ┌──────────────────────────────────────────────────────────┐ │ │
│  │  │ Prompt结构:                                              │ │ │
│  │  │                                                           │ │ │
│  │  │ # 单跳问答对（包含chunk）⭐⭐⭐                          │ │ │
│  │  │                                                           │ │ │
│  │  │ QA-1 (来自论文: Paper_A.pdf):                           │ │ │
│  │  │ 问题: 在低温下SAW谐振器的Q值为何提升？                  │ │ │
│  │  │ 答案: 低温下弹性模量增加，热致损耗降低...              │ │ │
│  │  │ 原始chunk（知识来源）:                                  │ │ │
│  │  │   [LiNbO₃的弹性模量在10mK时提升15-20%...]           │ │ │
│  │  │                                                           │ │ │
│  │  │ QA-2 (来自论文: Paper_B.pdf):                           │ │ │
│  │  │ 问题: 晶格旋转如何影响界面散射？                        │ │ │
│  │  │ 答案: 晶格旋转角度控制在<0.5°可抑制散射...            │ │ │
│  │  │ 原始chunk（知识来源）:                                  │ │ │
│  │  │   [HR-EBSD测量显示，XY方向旋转<0.5°...]              │ │ │
│  │  │                                                           │ │ │
│  │  │ ---                                                       │ │ │
│  │  │                                                           │ │ │
│  │  │ # 桥接信息                                               │ │ │
│  │  │ QA-1的答案中提到的'散射'是QA-2问题的核心概念          │ │ │
│  │  │                                                           │ │ │
│  │  │ # 目标                                                   │ │ │
│  │  │ 生成一个2跳的多跳问答对                                 │ │ │
│  │  │                                                           │ │ │
│  │  │ ---                                                       │ │ │
│  │  │                                                           │ │ │
│  │  │ ## 【核心要求】⭐⭐⭐                                    │ │ │
│  │  │                                                           │ │ │
│  │  │ 1. 基于chunk的约束（最高优先级）                        │ │ │
│  │  │    - 答案的每一句话都必须能在chunk中找到依据           │ │ │
│  │  │    - 只能重组和推理chunk中已有的信息                   │ │ │
│  │  │    - 禁止引入chunk外的任何事实、数据、结论             │ │ │
│  │  │                                                           │ │ │
│  │  │ 2. 问题设计准则                                          │ │ │
│  │  │    - 问题必须体现2步推理的必要性                       │ │ │
│  │  │    - 问题具有通用性（不特指某篇论文）                  │ │ │
│  │  │    - 问题单一（不包含多个子问题）                      │ │ │
│  │  │                                                           │ │ │
│  │  │ 3. 答案生成准则                                          │ │ │
│  │  │    - 必须完整回答问题                                   │ │ │
│  │  │    - 必须体现2步推理过程                               │ │ │
│  │  │    - 每个推理步骤都要引用chunk                          │ │ │
│  │  └──────────────────────────────────────────────────────────┘ │ │
│  └────────────────────────────────────────────────────────────────┘ │
│                            │                                          │
│                            ▼                                          │
│  ┌────────────────────────────────────────────────────────────────┐ │
│  │ Step 3.2: LLM生成                                              │ │
│  │                                                                 │ │
│  │  LLM配置:                                                      │ │
│  │  ├─ Model: Qwen2.5-72B-Instruct / Llama3-70B                  │ │
│  │  ├─ max_tokens: 3000                                           │ │
│  │  ├─ temperature: 0.7 (适度创新)                               │ │
│  │  └─ Output format: JSON                                        │ │
│  │                                                                 │ │
│  │  LLM思考过程:                                                  │ │
│  │  ┌─────────────────────────────────────────────────────────┐  │ │
│  │  │ 1. 理解单跳QA的核心内容                                 │  │ │
│  │  │    - QA-1: 低温 → 弹性模量↑ + 损耗↓ → Q值↑            │  │ │
│  │  │    - QA-2: 晶格旋转<0.5° → 散射↓                       │  │ │
│  │  │                                                          │  │ │
│  │  │ 2. 识别桥接关系                                          │  │ │
│  │  │    - QA-1提到"散射损耗"                                 │  │ │
│  │  │    - QA-2讨论如何降低"散射"                             │  │ │
│  │  │    → 因果链: 低温+晶格控制 → 散射↓ → 性能↑            │  │ │
│  │  │                                                          │  │ │
│  │  │ 3. 合成多跳问题                                          │  │ │
│  │  │    结合两个单跳的核心概念，形成需要两步推理的问题       │  │ │
│  │  │                                                          │  │ │
│  │  │ 4. 基于chunk生成答案                                     │  │ │
│  │  │    - 从QA-1的chunk提取: 弹性模量数据                   │  │ │
│  │  │    - 从QA-2的chunk提取: 晶格旋转阈值                   │  │ │
│  │  │    - 组织推理链，确保每步都有chunk支撑                  │  │ │
│  │  └─────────────────────────────────────────────────────────┘  │ │
│  └────────────────────────────────────────────────────────────────┘ │
│                            │                                          │
│                            ▼                                          │
│  ┌────────────────────────────────────────────────────────────────┐ │
│  │ Step 3.3: 解析LLM输出                                          │ │
│  │                                                                 │ │
│  │  输出JSON:                                                      │ │
│  │  {                                                              │ │
│  │    "multihop_question": "...",                                 │ │
│  │    "multihop_answer": "...",                                   │ │
│  │    "reasoning_steps": [                                        │ │
│  │      {                                                          │ │
│  │        "step": 1,                                              │ │
│  │        "content": "低温下弹性模量提升15-20%...",              │ │
│  │        "based_on": "单跳QA-1",                                │ │
│  │        "chunk_reference": "LiNbO₃的弹性模量..." ⭐           │ │
│  │      },                                                         │ │
│  │      {                                                          │ │
│  │        "step": 2,                                              │ │
│  │        "content": "晶格旋转控制在<0.5°可抑制散射...",         │ │
│  │        "based_on": "单跳QA-2",                                │ │
│  │        "chunk_reference": "XY方向旋转<0.5°..." ⭐            │ │
│  │      }                                                          │ │
│  │    ],                                                           │ │
│  │    "key_concepts": ["热致损耗", "界面散射"],                  │ │
│  │    "bridge_type": "causal"                                     │ │
│  │  }                                                              │ │
│  │                                                                 │ │
│  │  容错解析:                                                      │ │
│  │  ├─ 提取```json ... ```中的JSON                              │ │
│  │  ├─ 或提取第一个{...}                                         │ │
│  │  └─ 失败时返回空dict                                          │ │
│  └────────────────────────────────────────────────────────────────┘ │
│                                                                       │
│  输出:                                                               │
│  ├─ question: 多跳问题                                              │
│  ├─ answer: 多跳答案（基于chunk）                                   │
│  ├─ reasoning_steps: 推理步骤（带chunk引用）⭐                      │
│  └─ key_concepts: 核心概念                                          │
│                                                                       │
└──────────────────────────────────────────────────────────────────────┘
                             │
                             ▼
┌──────────────────────────────────────────────────────────────────────┐
│ 阶段4: 多阶段质量保障（3层检查）⭐⭐⭐                                │
├──────────────────────────────────────────────────────────────────────┤
│                                                                       │
│  ┌────────────────────────────────────────────────────────────────┐ │
│  │ 质量保障层1: 8维度评估 + 迭代优化                             │ │
│  ├────────────────────────────────────────────────────────────────┤ │
│  │  FOR round IN [0, 1, 2]:  # 最多3轮                           │ │
│  │                                                                 │ │
│  │    ① 8维度质量评估                                            │ │
│  │       ├─ 问题通用性、回答相关性、逻辑一致性                   │ │
│  │       ├─ 术语使用、事实正确性、答案通用性                     │ │
│  │       ├─ 答案完整性、答案可靠性（含chunk检查）⭐              │ │
│  │       └─ overall_quality = high/medium/low                     │ │
│  │                                                                 │ │
│  │    ② 决策                                                      │ │
│  │       IF quality == 'high': BREAK                              │ │
│  │       ELSE: 继续优化 ↓                                         │ │
│  │                                                                 │ │
│  │    ③ 优化（基于原始答案+chunk）⭐                             │ │
│  │       ├─ 参考原始答案（保留核心）                             │ │
│  │       ├─ 参考chunk（补充信息）                                │ │
│  │       ├─ 根据建议针对性改进                                   │ │
│  │       └─ 记录优化历史                                          │ │
│  │                                                                 │ │
│  │  输出: 优化后的QA + quality_evaluation                        │ │
│  └────────────────────────────────────────────────────────────────┘ │
│                            │                                          │
│                            ▼                                          │
│  ┌────────────────────────────────────────────────────────────────┐ │
│  │ 质量保障层2: 4重增强质量检查（并发执行）⭐                    │ │
│  ├────────────────────────────────────────────────────────────────┤ │
│  │  并发执行4个独立检查:                                          │ │
│  │                                                                 │ │
│  │  ┌──────────────────────────────────────────────────────────┐ │ │
│  │  │ Check 1: 有效性检查                                      │ │ │
│  │  │  - 10项有效性标准                                        │ │ │
│  │  │  - 重点检查chunk依赖                                     │ │ │
│  │  │  - 输出: pass/fail                                       │ │ │
│  │  └──────────────────────────────────────────────────────────┘ │ │
│  │  ┌──────────────────────────────────────────────────────────┐ │ │
│  │  │ Check 2: 直接生成测试                                   │ │ │
│  │  │  - LLM直接回答问题（带chunk参考）                       │ │ │
│  │  │  - 生成3次（temperature=0.8）                           │ │ │
│  │  │  - 计算一致性 ≥ 0.5                                     │ │ │
│  │  └──────────────────────────────────────────────────────────┘ │ │
│  │  ┌──────────────────────────────────────────────────────────┐ │ │
│  │  │ Check 3: LLM判断答案                                    │ │ │
│  │  │  - 比较生成答案与标准答案                               │ │ │
│  │  │  - 基于chunk信息判断                                    │ │ │
│  │  │  - 输出: Correct/Incorrect                              │ │ │
│  │  └──────────────────────────────────────────────────────────┘ │ │
│  │  ┌──────────────────────────────────────────────────────────┐ │ │
│  │  │ Check 4: 替代答案检查                                   │ │ │
│  │  │  - 验证直接生成的答案是否也正确                         │ │ │
│  │  │  - 基于chunk信息判断                                    │ │ │
│  │  │  - 输出: yes/no                                         │ │ │
│  │  └──────────────────────────────────────────────────────────┘ │ │
│  │                                                                 │ │
│  │  汇总:                                                          │ │
│  │  overall_passed = (validity AND consistency≥0.5 AND            │ │
│  │                    (judgment=='Correct' OR alternative==yes))  │ │
│  │                                                                 │ │
│  │  输出: enhanced_quality_checks                                 │ │
│  └────────────────────────────────────────────────────────────────┘ │
│                            │                                          │
│                            ▼                                          │
│  ┌────────────────────────────────────────────────────────────────┐ │
│  │ 质量保障层3: 25项最终验证                                     │ │
│  ├────────────────────────────────────────────────────────────────┤ │
│  │  全面检查清单:                                                 │ │
│  │                                                                 │ │
│  │  A. 问题质量（6项）                                           │ │
│  │     ├─ 清晰性、通用性、单一性                                 │ │
│  │     ├─ 多跳推理必要性                                         │ │
│  │     └─ 术语准确性、实际价值                                   │ │
│  │                                                                 │ │
│  │  B. 答案质量（8项）⭐ 含chunk检查                            │ │
│  │     ├─ 准确性、完整性、简洁性                                 │ │
│  │     ├─ 通用性、术语准确性、逻辑性                             │ │
│  │     ├─ 基于单跳QA                                             │ │
```

## 🎯 关键技术点

### **1. 智能桥接算法** ⭐⭐⭐

**核心思想**：答案中的实体 → 下一个问题的主体

```python
# 简化版算法
def find_bridgeable_qas(base_qa):
    # 1. 从base_qa的答案中提取实体
    entities = extract_keywords(base_qa.answer)
    # ["散射", "载流子", "Q值"]
    
    # 2. 找到问题中包含这些实体的QA
    candidates = []
    for entity in entities:
        for qa in all_qas:
            if entity in qa.question:
                candidates.append((qa, entity))
    
    # 3. 优先跨论文
    cross_paper = [qa for qa, _ in candidates 
                   if qa.paper != base_qa.paper]
    
    return cross_paper or candidates
```

### **2. Chunk约束生成** ⭐⭐⭐

**3层约束机制**：

```
Prompt层: 明确要求"所有信息必须来自chunk"
  ↓
生成层: LLM基于chunk重组和推理
  ↓
验证层: 8维度评估 + 4重检查 + 25项验证
```

### **3. 质量感知批控制** ⭐
